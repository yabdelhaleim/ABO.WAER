## Cart System — DB-driven catalog + persistent cart

### Key constraint that shapes everything

`resources/js/cart.js` and `resources/views/cart.blade.php` stay **byte-identical**. The Blade already maps `$products` (arrays keyed `slug/name/price/image/category/colors`) into the `<script type="application/json" data-cart-products>` tag, and `cart.js` prices every line off that tag. So I feed DB data into the **exact same array shape** — no view change, no JS change, UI untouched.

This also keeps `tests/Feature/CartTest.php` green: `CatalogSeeder` mirrors `home.php` exactly (same slugs, names, prices, colors, image paths), so its 26 assertions still hold against a DB-backed payload.

### 4. `App\Services\CartService` — all the arithmetic

Constants: `MAX_QUANTITY_PER_LINE = 10` — matches `cart.js`'s `MAX_QTY_PER_LINE`, honouring the contract already written in that file's header comment.

| Method | Behaviour |
|---|---|
| `getStorefrontCatalog(): array` | Active products (`is_archived = false`) that have ≥1 variant, `orderBy('id')`, eager-loads `category`, `colors`, `variants`, `productColors.images`. `price` = min `final_price` across **in-stock** variants, falling back to min across all. `image` = `primary_image?->path`. `colors` = hex codes. Returns the array shape `cart.blade.php` already expects. |
| `addItem(?Customer, string $sessionId, array): CartItem` | Validates variant belongs to an active product; rejects `quantity > variant->quantity` and `> 10` via `ValidationException` (→ 422). Same variant again **increments** the existing line (clamped to stock/10) instead of inserting a duplicate. `DB::transaction()`. |
| `updateItem(CartItem, int): CartItem` | Clamps to stock and to 10. |
| `removeItem(CartItem): void` | Deletes the line. |
| `getSummary(?Customer, string $sessionId): array` | `items`, `item_count`, `subtotal`, `free_shipping_threshold` (from `ShippingSetting`), `free_shipping_enabled`, `qualifies_for_free_shipping`, `remaining_for_free_shipping`. |
| `mergeGuestCart(Customer, string $sessionId): void` | Moves session lines onto the customer, **summing** quantities per variant and clamping to stock; deletes session rows. `DB::transaction()`. |
| `mergeClientCart(Customer, array $lines): array` | Sync from the localStorage payload. Resolves `{slug, color, qty}` → variant (exact color match, else cheapest in-stock variant of that slug), clamps to stock, reports `{merged, skipped}`. `DB::transaction()`. |
| `assertOwned(CartItem, ?Customer, string $sessionId): CartItem` | Throws `ModelNotFoundException` (→404) if the row's `customer_id`/`session_id` doesn't match the caller. Stops one customer (or one guest session) from PATCHing another's cart by guessing IDs. |

The free-shipping comparison lives **only** in this service and the JSON summary — never on the page, because the existing test `test_no_free_shipping_threshold_or_progress_bar_rendered` forbids a progress bar or "FREE SHIPPING" copy.
