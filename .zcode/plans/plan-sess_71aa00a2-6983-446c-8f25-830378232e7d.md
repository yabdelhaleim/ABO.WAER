## Phase 9 — Step 2: SEO, Sitemap & Custom Error Pages

### ⚠️ تصحيحات ضرورية على المواصفات (اكتُشفت من الكود الفعلي)

المواصفات المُرسلة استخدمت أسماء غير موجودة في هذا المشروع. commitment detonates here — سأتبع الكود الفعلي:

| في المواصفات | الكود الفعلي | القرار |
|---|---|---|
| `route('shop.index')` | `shop` | نستخدم `route('shop')` |
| `route('products.show')` | `shop.show` (المسار `/shop/{slug}`) | نستخدم `route('shop.show', $slug)` |
| `route('pages.show')` | `about` / `contact` / `shipping` / `returns` / `exchange` | نستخدم `route($page->slug)` مع whitelist |
| `store/products/show.blade.php` | `resources/views/product.blade.php` | نعدّل الملف الفعلي |
| `Category::active()` | غير موجود | نضيف الـ scope للنموذج |
| صفحات أخطاء بالعربية | المتجر كله `<html lang="en">` | إنجليزي (كما نصّت نسختك المعدّلة) |
| `Sitemap: {{ config('app.url') }}/sitemap.xml` في ملف ثابت | ملفات `public/` لا تمرّ على Blade | نكتب الرابط الحرفي |

**الأهم:** المواصفات أخّرت `sitemap.xml` و `robots.txt` إلى `/products/{slug}` و `https://abostore.com` — لكن الكود الفعلي يستخدم `/shop/{slug}`. سأبني على الكود الفعلي.

### 1) `app/Models/Category.php` — إضافة scope

```php
/**
 * Scope: only categories visible to shoppers.
 */
public function scopeActive($query)
{
    return $query->where('is_active', true);
}
```
`Product::scopeActive()` موجود بالفعل ولا يُمس.

### 2) `app/Http/Controllers/SitemapController.php` (جديد)

```php
public function index(): Response
```
- `Product::active()->select(['slug', 'updated_at'])->orderBy('id')->get()`
- `Category::active()->select(['slug', 'updated_at'])->orderBy('sort_order')->get()`
- `Page::where('is_active', true)->whereIn('slug', self::CONTENT_ROUTES)->select([...])->get()`
- `const CONTENT_ROUTES = ['about', 'contact', 'shipping', 'returns', 'exchange'];` — لأن أسماء المسارات = الـ slugs، والـ whitelist يمنع كسر `route()` لو أُضيف slug عشوائي لاحقاً.
- يُرجع `response()->view('sitemap', compact(...))->header('Content-Type', 'application/xml')`

`select()` مقصور على الأعمدة المستخدمة → لا N+1 ولا أعمدة زائدة.

### 3) `resources/views/sitemap.blade.php` (جديد)

هروب تلقائي عبر `{{ }}` (يحوّل `&` → `&amp;` وهو XML صحيح). جدول مع Razor comments يشرح كل كتلة — نفس أسلوب المشروع:

| الكتلة | priority | changefreq | lastmod |
|---|---|---|---|
| `/` | 1.0 | daily | — |
| `/shop` | 0.9 | daily | — |
| `/shop?category={slug}` | 0.8 | weekly | `updated_at` |
| `/shop/{slug}` | 0.7 | weekly | `updated_at` |
| صفحات المحتوى | 0.5 | monthly | `updated_at` |

### 4) `routes/web.php` — مسار واحد

داخل مجموعة `Store: Public` الحالية (خارج Auth):
```php
Route::get('/sitemap.xml', [SitemapController::class, 'index'])->name('sitemap');
```
⚠️ `sitemap.xml` لا يُعترض بـ `/shop/{slug}` — لا تعارض.

### 6) `resources/views/layouts/store.blade.php` — OG/Twitter ديناميكي

استبدال الـ OG block الثابت بـ sections. **مهم:** `<title>` يُلحق بـ `— Premium Men's Streetwear`، لذلك section منفصل `og_title` حتى لا يحصل OG card على اللاحقة.

```blade
@php $ogImage = asset(yield('og_image', 'images/streetwear-hero.jpg')); @endphp
<link rel="canonical" href="{{ url()->current() }}">

<meta property="og:type" content="@yield('og_type', 'website')">
<meta property="og:site_name" content="ABO">
<meta property="og:title" content="@yield('og_title', 'ABO — Modern fit, urban vibe.')">
<meta property="og:description" content="@yield('description', ...)">
<meta property="og:url" content="{{ url()->current() }}">
<meta property="og:image" content="{{ $ogImage }}">
<meta property="og:image:alt" content="@yield('og_image_alt', 'ABO')">
@yield('og_extra')

<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="@yield('og_title', 'ABO')">
<meta name="twitter:image" content="{{ $ogImage }}">
```

`og_image` يُستخدم كقيمة relative ويمرّ بـ `asset()` → **absolute URL** (شرط WhatsApp/Facebook).

### 7) `resources/views/product.blade.php` — كارت المنتج

```blade
@section('og_type', 'product')
@section('og_title', $product->name)
@section('og_image', $product->primaryImage?->path ?: 'images/streetwear-hero.jpg')
@section('og_image_alt', $product->name)
@section('og_extra')
    <meta property="product:price:amount" content="...">
    <meta property="product:price:currency" content="EGP">
    <meta property="product:availability" content="in stock">
@endsection
```

`$product->primaryImage` يعتمد على eager-loaded relation (`productColors.images`) → لا lazy loading.

### 8) صفحات الأخطاء — 3 ملفات + CSS

`resources/views/errors/{404,403,500}.blade.php` — كلها `@extends('layouts.store')`، so the layout يضمن نفس nav + footer + tokens.

⚠️ **تحذير recursion:** الـ layout يعمل `@vite()`. لو فشل الـ Vite manifest، الخطأ يرمي استثناءً → 500 داخل 500 → infinite recursion. هذا يحدث في `errors/500.blade.php` فقط. الحل: `@section('scripts')` في صفحة 500 يحوي fallback CSS بـ `<style>` مضمّن ولا يستدعي `asset()`.

`resources/css/errors.css` (جديد) + `@import './errors.css';` في `app.css` — نفس نمط `orders.css`/`content.css` القائم. يعيد استخدام `.store-btn--primary` و `--abo-lime`，无需 ألوان جديدة.

### 9) `tests/Feature/SeoAndErrorPagesTest.php` (جديد)

| # | الاختبار | التحقق |
|---|---|---|
| 1 | sitemap responds correctly | 200 + `application/xml` + `<urlset>` |
| 2 | sitemap is valid XML | `simplexml_load_string` !== false |
| 3 | lists active products | slug موجود / archived **غير** موجود |
| 4 | lists active categories | `/shop?category=slug` موجود / inactive **غير** موجود |
| 5 | lists active content pages | موجود / `is_active=false` **غير** موجود |
| 6 | robots.txt references sitemap | يقرأ `public/robots.txt` ويتحقق من `Sitemap:` + الـ Disallow |
| 7 | custom 404 | نص العلامة + زر المتجر، **وليس** صفحة Laravel البيضاء |
| 8 | 403 view exists | `View::exists('errors::403')` |
| 9 | 500 view exists | `View::exists('errors::500')` |
| 10 | product OG tags | `og:image` بصورة المنتج + `product:price:currency` |

`Content-Type` يُقرأ بـ `$response->headers->get('Content-Type')` — `assertHeader` حسّاس لـ `; charset=` suffix.
